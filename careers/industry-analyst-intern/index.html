具身智能行业分析员（实习）

深圳 · 每周 3 天以上 · 连续 2 个月以上 · 薪酬面议

工作地点：深圳南山区深圳大学城学历要求：本科及以上在读或应届直接与创始人一起工作

一、关于我们

我们是一家专注于具身智能产业落地的科技公司。核心研发与工程班底由清华、人大硕博及资深机器人研发人员组成，技术能力覆盖物理大模型训练、端侧推理、视觉伺服、机器人系统集成与工业现场交付。

团队并非停留在仿真或演示阶段。目前我们已经打通数据采集、模型训练、真机部署、现场调优与数据回流的完整技术链路，相关系统已在深圳真实工厂完成落地验证，正在持续推进制造业柔性上下料等场景。

这个岗位不写代码、不调机器，但决定我们对行业的判断有多准。你会直接与创始人一起工作。

二、这个岗位做什么

三块工作，按时间占比：

  1. 五成：梳理行业的技术发展路径。把具身智能 / 物理大模型的技术路径按数据、模型架构、训练范式、本体、部署方式拆开，画成一张持续维护的路线图；把国内外主要公司和研究团队的路径一一对应到图上，说明各自的选择、进展和证据。
  2. 三成：竞争对手分析。跟踪国内外主要公司的技术路径、融资与估值、业务与客户、组织与人才流动，形成结构化的对手档案，按季度更新，并对关键变化给出你的判断。
  3. 两成：政策、赛事与资源。梳理各地政府与具身智能、机器人相关的政策与补贴，创业比赛与评选，产业园区、协会与产业资本等资源，形成可执行的申报 / 参赛日历，并协助对接。

三、任职要求

  1. 本科及以上在读或应届，专业不限 —— 经管、计算机、自动化、机器人、公共政策都可以；
  2. 对人工智能与机器人有真实的兴趣，能读懂技术论文和技术博客的主线，分得清「说了什么」和「证明了什么」；
  3. 英文阅读流畅，能直接跟踪海外公司与论文；
  4. 结构化写作能力：能把复杂的信息压成一页纸，让读的人两分钟看懂；
  5. 信息检索与核实能力，有出处意识 —— 每一个数字都能说出来自哪里；
  6. 能够在深圳现场实习，每周到岗不少于 3 天，连续实习不少于 2 个月。

四、优先考虑

  1. 有投资机构、咨询、产业研究或科技媒体的实习经历；
  2. 系统跟踪过具身智能或大模型行业，并有自己的输出 —— 公众号、知乎、Newsletter、研究报告都算；
  3. 会用 Python 或现成工具做数据抓取与整理；
  4. 参与过创业比赛或政府项目申报，知道材料是怎么做出来的。

五、你将获得

  1. 直接与创始人一起工作，参与公司对行业与战略的讨论；你的路线图和分析会真正被用于决策；
  2. 有机会与投资机构、产业伙伴和政府部门直接接触，看到一家早期公司是怎么被外界看待和推动的；
  3. 输出物经保密审核后可以公司名义发布，署名按实际贡献确定；
  4. 团队每年可推荐符合条件的优秀实习生申请清华大学、中国人民大学的硕士与博士研究生；
  5. 提供正式实习证明；
  6. 根据能力和实际贡献提供有竞争力的实习薪酬，表现优异者优先进入转正通道；转正后可按公司统一标准参与股权激励计划。
